# v4c：在认证链上做定时到达任务（F8D2000B 构型库，扰动 + 模型失配，纯强化学习）

分支 `certified-v4`。这一版**不用快速模型飞行**：飞行器的每一步都经过原工程的认证链执行，
只有策略内部的"预测"用名义质点模型（这是设计者手里的模型，本来就应该是名义的）。按要求**不跑对比方法**。

## 任务

- 固定飞 1200 s，在 1200 s 时航程误差 ≤ 5 km、末速误差 ≤ 25 m/s，且全程不超限，算命中（同 v2）。
- 扰动：L2（密度场 σ 6%、相关长度 200 km；升阻偏差 5%；初始高度、速度偏差）。
- 模型失配（同 v3，人为设定，无物理依据）：刹车构型增阻效果 ×0.6，阻力 +20%，阻力随马赫数斜率 +10%/Ma（Ma 6 为零点），升力 −5%。

## 每一步怎么飞（3 s 一个认证决策，策略 12 s 一个决策）

1. 策略每 12 s 给出升力系数目标的增量（±0.0025 / ±0.005 / 0）和变构程度 w（0、0.2、…、1.0 共 6 档）。
2. 期望升力系数 = 目标 − 航迹角反馈，再经保护回路抬高（动压律，用在线升力估计修正；动压目标 0.90 倍上限；高度下限律）。
3. **认证链**：认证器按"离期望升力系数最近"的顺序试探链上的 19 个升力系数动作，执行最近的一个通过认证的动作：
   - 几何生成器按 w 在 F8D2000B 的 2091 个构型里选"等升力下阻力档位最接近 w"的构型（w = 0 即原来的最小阻力构型），8 s 过渡；
   - 代理模型（两段 OCP 的近似：预测马赫数 + 6 个 0.5 s 迎角指令），超出覆盖范围时用精确物理基线；
   - 后置校正器、30 s 前视保护、0.1 s 审计，全部在**名义模型**上做。
   - 真实 OCP 兜底关闭（太慢）：此时该动作算未认证。
4. **真实运动**由"真实对象"积分（`certified_flight/truth.py`）：同一个编译好的质点模型，加上扰动和失配。认证器不知道这些。
5. 失败：没有任何动作能通过认证、执行被拒绝、真实对象超限（包括马赫数低于气动表范围）。

## 代理模型重训（换了构型库，必须重训）

| 步骤 | 内容 |
|---|---|
| 快照 | `scripts/v4c_build_snapshot.py`：F8D2000 + 91 个刹车构型 → 认证链格式（`data/geometry_f8d2000b`），检查升力曲线单调 |
| 采样 | `scripts/v4c_collect_contexts.py`：用精确物理基线飞 64 次（场景 5000–5063，起点规则 + 40% 随机动作，覆盖刹车构型），抽 1500 个决策上下文，按飞行分训练/验证/测试 |
| 标签 | `scripts/aoa_generate_labels.py --objective aligned`：每个上下文解一次两段 OCP（教师） |
| 拟合 | `scripts/aoa_fit_surrogate.py`：同原工程的核岭回归代理模型 |
| 合格检验 | `scripts/aoa_qualify_surrogate.py`：验证、测试标签上，校正后的计划 0.1 s 审计零失败（P1 门槛），否则前视保护拒绝使用这个代理模型 |

## 规模（按本机 4 核缩小）

一次认证飞行约 1 分钟（快速模型约 0.3 秒），所以规模比快速模型版小很多：

| 项 | 数量 |
|---|---|
| 训练场景 / 采纳场景 | 32（1100–1131）/ 32（1400–1431），采纳规则同 v3b |
| 训练 | 最多 20 轮，每轮 4 个场景 × 12 个决策时刻 × 4 个反事实分支；连续 8 轮没有采纳就停 |
| 验证集 | 48 个场景（1600–1647）× 2 个目标 = 96 个 |
| 任务域地图 | 4 个场景 × 网格点（距离步长 200 km、末速步长 200 m/s） |
| 目标区域 | 在认证链上飞两段常值计划（升力系数 6 档 × 6 档，变构 5 种组合；固定外形 36 个），名义场景 + 失配 |
| 测试集 | 2400–2419，未使用 |

## 运行

```bash
JOBS=4 bash scripts/run_v4c.sh          # snapshot contexts labels fit qualify install region train eval report
```

每个阶段可续跑。结果在 `runs/v4c/F8D2000B/`：`V4C_REPORT_validation.md`、`V4C_domain_map.png`、`train/rel_s17/state.json`、
代理模型 `data/surrogate_v4c/`、合格检验 `data/lookahead_v4c/AB_metrics.json`。

## 和原工程相比改了什么

| 文件 | 改动（默认行为不变） |
|---|---|
| `certified_flight/aero.py` | 几何生成器可按阻力档位 w 选构型（`db.level`，默认 None = 最小阻力） |
| `certified_flight/environment.py` | 起始构型可配置；执行运动通过 `propagate()`，可换成真实对象；可关闭真实 OCP 兜底；上下文里带 `morph_level` |
| `certified_flight/certification.py` | 提交时用同一个 `propagate()` 重新积分（有真实对象时） |
| `certified_flight/build.py` | 运行配置文件可用环境变量 `CF_RUNTIME` 指定 |
| `certified_flight/distill.py` | 教师标签按上下文的 `morph_level` 选构型 |
| `certified_flight/truth.py`（新） | 真实对象 |
| `target_rl/chain.py`（新） | 认证链上的定时到达飞行，接口同快速模型版，训练、评估代码不变 |
| `target_rl/region.py`、`guided.py`、`train.py` | 认证链上的目标区域；名义预测不带失配；`chain` 类型 |
