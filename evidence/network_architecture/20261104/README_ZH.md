# 优势网络结构实验原始数据

本目录于2026-11-04补充发布既有离线网络结构实验。没有重新训练、追加飞行、修改原始数据或重新选择实验结果。

## 数据范围

- 17种网络结构，包括线性、单隐藏层、两至六隐藏层，加宽至每层128个神经元。
- 来源为bc_seed17、bc_seed23、bc_seed41三个训练种子的历史优势标签档案；每种结构共62个前向时间块记录。
- 每个成员网络输入为归一化的h、V、gamma、t，输出19个动作的优势；每组使用5成员集成。
- 前向评估以此前标签拟合，预测后续时间块标签。此处的三个seed是来源策略种子，不应误称三个相同数据集上的独立拟合种子。

## 文件

- `raw/`：85个原始文件，逐字节保留，包括逐块真实标签/预测/评分、汇总JSON、生成及分析脚本、日志以及空错误日志。
- `inputs/bc_seed17.json`、`bc_seed23.json`、`bc_seed41.json`：研究脚本使用的来源策略及标签档案。
- `STRUCTURE_METRICS.csv`：将原`raw/summary.json`的34条统计转写成CSV（17结构×all/new两个子集），另列架构与单成员参数数目。
- `PROVENANCE.json`：来源文件路径、尺寸和SHA256。
- `SHA256SUMS`：除自身、ZIP及其外部校验文件外的证据文件哈希；ZIP内带同一清单。
- `network_architecture_20261104.zip`、`ARCHIVE_SHA256SUMS`：本目录证据的独立下载包及ZIP校验值。

## 主要结果与统计口径

`all`子集的原排序指标：16-16为0.530703636293227，64-64-64-64为0.6465507493319909，64x6为0.654853425241064。
指标在每个时间块内对跨状态动作对的预测增益和实测增益排序，再对块取平均；不是逐状态完整19动作的准确率。
统计沿用原`summarize.py`，包括双argsort的秩处理和下截断目标，不在此次发布中替换为新的指标实现。并列值处理以原代码为准。
`new`是原脚本按完整features元组识别的子集，不应直接等同于按实际四维网络输入严格去重的独立新状态集。
这些是训练标签上的结构选择诊断，不是独立留出飞行测试。

四层64和两层16的后续闭环对照已在本分支继承的[held-out-2原始报告](../../../cloud_results/v14_final/summaries/heldout2/RESULTS.md)公开。
四层64虽提高上述离线排序指标，却没有改善该闭环测试结果；本次不删除失败或改写结论。
