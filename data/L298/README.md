# L298：项目原有的 298 构型快照（主实验）

本目录只放了本研究用到的气动张量 `p2_grid.npz`（[298 构型, 18 Mach, 20 迎角]，原 P2 表面压力模型），
来自主工程 `data/geometry_subset/aerodynamics/p2_grid.npz`，SHA256 与原清单 `manifest.json` 一致（见 `SHA256SUMS`）。
固定构型对照用 G42（项目的初始构型）。

`README_ZH.txt` 是原快照的说明，里面提到的几何文件、等升力表、基准和来源记录没有复制进本分支，
需要时到主工程的 `data/geometry_subset/` 查看。
