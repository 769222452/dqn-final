# BrakeLadder：91 个前缘不变的"减速板"构型（F8D2000B 的新增部分）

F8D2000B = F8D2000 的 2000 个构型 + 本目录的 91 个构型，共 2091 个，前缘全部固定为 G42 的三维前缘。设计、证据和
复现方法见 `library-design` 分支的 `docs/LIBRARY_DESIGN.md`。

## 组成

每个母构型（G42、F2K_01233、F2K_00021，网格取自 F8D2000 的 `references/`）各约 30 个：

| 类型 | 数量 | 变形 |
|---|---|---|
| 母构型本身 | 3 | 不变形 |
| 前部弯度 | 27 | 上下表面同向位移 c·B_front，c = −0.04、−0.02、0.02、0.04、0.06、0.08、0.10、0.13、0.16 m |
| 后部弯度 | 27 | 同上，B_rear |
| 襟翼弯度 | 27 | 同上，B_flap = c_row·t⁴ |
| 尾部削薄 | 7 | 上表面尾部 +k·0.04 m、下表面尾部 −k·0.035 m，k = 0.5～3（共 18 个，11 个尾缘厚度为负被筛掉） |

基函数与 F8D2000 相同（`datasets/F8D2000/config.json`），另加襟翼 t⁴。所有基函数在前缘列和塌缩翼尖行上为零，
所以前缘、x/y 网格、平面形状和 5 m 长度都和母构型相同。

## 筛选

- 几何有效：无流向折叠，上下表面厚度不为负；
- 体积不小于 0.4687 m³（F8D2000 的最小值），实际为 0.59～1.05 m³；
- 全部 18 个马赫数 × 20 个攻角的网格点上 P2 有效。

## 气动

P2 表面压力模型的 Python 移植版，与 F8D2000、L298 存的气动表逐点核对，误差 10⁻¹⁵ 量级。张量格式与 F8D2000 的
`p2_grid.npz` 相同，另存了 `parents`、`names`、`upper`、`lower`（变形系数，m）和 `volume`。

## 用途

这些构型在所有工况下都比低阻构型阻力大（同升力下最高约 4 倍），用来在定点到达任务中耗能。它们是弯度较大的外形
（最大约 0.16 m，机身长 5 m），机构可实现性、结构和热载荷都没有验证；8 s 变构过渡也没有计入。
